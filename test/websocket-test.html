Speech2Text WebSocket Test

This page records microphone audio or accepts an audio file, sends it as a single transcribe request over WebSocket, and streams queue, start, delta, done, and error events from the backend.

Use this from a secure origin such as https:// or http://localhost so the browser allows microphone access. Selected audio or video files are sent as-is to the WebSocket server, which writes the decoded bytes directly to its ffmpeg input file. For video files, ffmpeg extracts the audio stream.
